# CodedOK — Meta ads upload pack

Everything for the first campaign. In Ads Manager, each ad uses **both**
image sizes for the same number: upload the `feed-4x5` and the
`story-9x16` file together, and Meta shows the right one per placement.

## Campaign settings

| Setting | Value |
|---|---|
| Objective | **Leads** |
| Conversion location | Website |
| Pixel / event | CodedOK website → **Lead** |
| Budget | £20/day, campaign budget (Advantage+) |
| Location | United Kingdom, Ireland |
| Age | 25–65 |
| Audience | Advantage+ audience. Suggestions: Boating, Sailing, Yachting, Boat charter, Fishing charter, Royal Yachting Association |
| Placements | Advantage+ placements |
| Website URL | `https://codedok.com/founding` |
| URL parameters | `utm_source=facebook&utm_medium=paid&utm_campaign=launch&utm_content={{ad.name}}` |
| Call to action button | **Sign up** |

Name each ad exactly as below (e.g. `1-pain`). The URL parameter puts that
name on every signup in the waitlist table, so you can see which ad won.
