### Export

The SVGs are vector and infinitely scalable. To turn them into uploadable PNG/JPG:

- **Quickest:** drop the SVG into <https://cloudconvert.com/svg-to-png> → set DPI to 144 → download
- **From design tools:** open in Figma, Canva, or Sketch → export PNG at 2x
- **From the terminal:**
  ```bash
  brew install librsvg
  rsvg-convert -w 1080 profile-1080.svg -o profile.png
  ```

Save the exports somewhere central (Google Drive / Dropbox / Notion).

## Voice & tone

| Do | Don't |
|---|---|
| Plain English. Harbour-pub language. | Buzzwords. "Revolutionary." "Leverage." |
| Specific: "Tsunami IV", "Sport or Pleasure Code 2025" | Generic: "marine industry", "compliance solutions" |
| Skipper first. Software second. | Software first. |
| Photos of real boats, real surveyors, real decks | Stock illustrations of grinning models |
| Confident. "We built this." | Apologetic. "We hope you find this useful." |
| Short sentences. Short paragraphs. | Run-ons that read like a Linkedin post. |

## Content pillars (rotate these)

Aim for ~4 posts a week, mixed across these five pillars:

1. **🛟 Compliance moments** — "What does Cat 2 actually mean?" / "5 things surveyors check first" / "MGN 71 explained in 1 minute"
2. **⛵ Customer stories** — real skippers using CodedOK on real boats. Photo + 2 lines + name.
3. **🏗️ Behind the scenes** — building from Cushendall, Redbay partnership, McCollam visits, the workshop
4. **📲 Product moments** — short video / GIF of one specific feature (PDF import, surveyor share, inspection pack)
5. **📰 Industry news** — Sport or Pleasure Code 2025 updates, MCA notices, Workboat Code changes — interpreted for the small operator

---

## What NOT to post

- Long product roadmaps (nobody cares yet — wait for customers to ask)
- "Excited to announce" posts (write properly — "we shipped X" beats "excited to announce X")
- Negative posts about Sea-Flux or any competitor (never name them — let your work be the contrast)
- Memes that don't relate to the boat (off-brand)
- Generic marine stock photos
- Anything in landscape video — IG and FB push 9:16

---

## When to graduate

Once you hit ~500 followers AND ~50 paying customers, hire a part-time social/content person. Until then it's you. 30 minutes Sunday evening, write the week's posts, schedule with Buffer or Meta's own scheduler.
