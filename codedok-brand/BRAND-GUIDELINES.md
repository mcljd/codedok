# CodedOK Brand Guidelines

**Version 1.0 — April 2025**

---

## Logo

The CodedOK logo consists of two elements: the **icon mark** (wave + compliance tick) and the **wordmark** (CodedOK). These should always be used together unless space specifically requires the icon only.

### Files included

| File | Use |
|------|-----|
| `logo-primary-light.svg` | Main logo — light/white backgrounds |
| `logo-primary-dark.svg` | Main logo — dark/navy backgrounds |
| `logo-compact-light.svg` | Smaller contexts — light backgrounds |
| `logo-compact-dark.svg` | Smaller contexts — dark backgrounds |
| `logo-wordmark-light.svg` | Text only — light backgrounds |
| `logo-wordmark-dark.svg` | Text only — dark backgrounds |
| `logo-mono-black.svg` | Single colour — print, embroidery |
| `logo-mono-white.svg` | Single colour — dark print, apparel |
| `@2x.png` versions | Screen use at retina resolution |

### Clear space

Always maintain clear space around the logo equal to the height of the letter "C" in the wordmark. Never place other logos, text, or images within this zone.

### Minimum size

- Full logo: minimum 120px wide on screen, 40mm in print
- Icon only: minimum 20px, 8mm in print
- Do not use the wordmark below 80px wide

### What not to do

- Do not stretch or distort the logo
- Do not change the colours outside of the approved variants
- Do not place the light logo on a light background
- Do not add drop shadows, outlines, or effects
- Do not rotate the logo
- Do not rearrange the icon and wordmark

## Typography

CodedOK uses system fonts for all digital interfaces to ensure fast loading and native rendering across all devices.

### Font stack

```
-apple-system, BlinkMacSystemFont, 'Segoe UI', Helvetica, Arial, sans-serif
```

### Type scale

| Role | Size | Weight | Use |
|------|------|--------|-----|
| Display | 36–48px | 700 | Hero headlines |
| Heading 1 | 28–32px | 700 | Page titles |
| Heading 2 | 20–24px | 700 | Section headings |
| Heading 3 | 16–18px | 600 | Card titles, labels |
| Body | 15–16px | 400 | Main content |
| Small | 13–14px | 400 | Secondary info, metadata |
| Label | 11–12px | 600 | Uppercase tags, caps labels |

### Type rules

- Headlines: letter-spacing `-0.5px` to `-1px`
- Uppercase labels: letter-spacing `+0.07em` to `+0.1em`
- Body line-height: `1.6`
- Never go below `11px`

### Approved combinations

| Background | Logo version |
|------------|-------------|
| White `#FFFFFF` | `logo-primary-light` |
| Off White `#F1F5F9` | `logo-primary-light` |
| Navy Deep `#0A1628` | `logo-primary-dark` |
| Navy Mid `#1A3560` | `logo-primary-dark` |
| Ocean Cyan `#0891B2` | `logo-mono-white` |
| Photography (light) | `logo-primary-light` |
| Photography (dark) | `logo-primary-dark` |

### Never use

- Light logo on white or off-white backgrounds
- Dark logo on navy backgrounds
- Colour logo on busy photography without a backing panel
- Any logo version that reduces contrast below 3:1

## Voice & Tone

### What CodedOK sounds like

- **Direct** — no jargon, no waffle. Operators are busy people.
- **Confident** — this is the compliance tool for coded vessels. Own it.
- **Practical** — features over philosophy. What does it actually do?
- **Reassuring** — compliance is stressful. We make it less so.

✓ "Never miss a compliance deadline."
✓ "Your flares expire in 18 days."
✓ "Silver Sands is 100% compliant."

✗ "Empowering maritime professionals to achieve compliance excellence."
✗ "A revolutionary platform for the modern vessel operator."
